# devcontainer workshop

## Requirements

- docker desktop
- vscode with dev containers extenstion installed: ms-vscode-remote.remote-containers
- git installed locally

## How to install

- clone this repo in a local map on the computer
- open the folder in vscode
- vscode will ask to start the devcontainer, if it takes to long press F1 and type reopen in container
- first start will pull the image (5gb) and customize it
- if ther is an erro message regarding func, ignore it.
- press f1 and select reload window
